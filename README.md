# Week 2 - 자동차 경주 게임

### 기능 목록
- [ ] 콘솔 기본 출력
- [ ] 사용자 입력 받기 
  - 경주할 자동차의 이름을 입력받는다.
  - 이동 횟수를 입력받는다. 
- [ ] 자동차 이름 구분하기
  - 쉼표를 기준으로 구분하며, 5자 이하만 가능하다.
- [ ] 자동차 전진 기능
  - 자동차는 전진 혹은 멈출 수 있다.
  - 0~9 사이의 무작위 값을 구한 후 그 값이 4 이상일 때 전진한다.
    - 무작위 값을 구할 때 `Randoms.pickNumberInRange(0,9)`를 사용한다.
- [ ] 차수별 실행 결과 출력
- [ ] 게임 우승 결과 출력

### 예외 처리 항목
- 쉼표가 아닌 다른 기호가 포함된 경우
- 쉼표가 마지막에 온 경우
- 이름이 5자 초과인 경우
- 이름이 공백으로 비어있는 경우
- 시도할 횟수를 입력할 때 숫자가 아닌 값을 입력한 경우
