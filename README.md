# Week 2 - 자동차 경주 게임

### 기능 목록
- [x] 사용자 입력 받기 
  - 경주할 자동차의 이름을 입력받는다.
  - 이동 횟수를 입력받는다. 
- [ ] 자동차 이름 구분하기
  - 쉼표를 기준으로 구분하며, 5자 이하만 가능하다.
- [ ] 자동차 전진 기능
  - 자동차는 전진 혹은 멈출 수 있다.
  - 0~9 사이의 무작위 값을 구한 후 그 값이 4 이상일 때 전진한다.
    - 무작위 값을 구할 때 `Randoms.pickNumberInRange(0,9)`를 사용한다.
- [ ] 차수별 실행 결과 출력
- [ ] 게임 우승 결과 출력

### 예외 처리 항목
**자동차 이름 입력**
- 쉼표가 마지막에 온 경우
- 이름이 5자 초과인 경우
- 이름이 공백으로 비어있는 경우

**시도 횟수 입력**
- 숫자가 아닌 값을 입력한 경우
- 공백인 경우
- 정수값을 벗어날 경우

### 프로그래밍 요구 사항
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
  - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
